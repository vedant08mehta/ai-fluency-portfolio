# FL-03 — Consistency, Not Talent

## Portfolio Visual Direction

My portfolio uses a consistent visual identity across the Home, Work, About, and Contact pages.

### Typography

- Headings: Space Grotesk
- Body: Inter

Space Grotesk gives headings a modern technical feel while Inter keeps longer text clean and readable.

### Color System

- Accent: #14B8A6
- Near-black text: #0F172A
- Near-white background: #F8FAFC
- Secondary text: #475569

The palette keeps the portfolio mostly neutral, with teal used as the main accent for important elements and calls to action.

### Logo

A simple VM monogram is used as the portfolio logo/favicon.

The logo is intentionally minimal so it supports the portfolio identity without competing with the project work.

### Visual Mood

Clean, technical, calm, and modern.

The design should frame the work rather than compete with it.

## AI vs Real Work

### Real captures

Real screenshots should be used whenever they provide evidence of the actual work.

Examples:
- FlyRank research paper and results
- Moodify application
- Student Grievance classification demo

These are more useful than generated replacements because they show what I actually built.

### AI-generated visuals

AI-generated visuals should only be used for decorative or connective elements where they do not pretend to represent actual project work.

The VM logo is an example of a generated visual being used for portfolio identity rather than project evidence.

### Rejected AI Direction

I would reject generic AI-generated dashboards, fake code screenshots, or futuristic "AI" graphics used to represent my projects.

They may look polished, but they do not prove anything about the work I actually completed.

A real screenshot of the project is more valuable when the purpose is to demonstrate evidence.

## Consistency Rules

1. Use Space Grotesk for headings throughout the portfolio.
2. Use Inter for body text.
3. Keep the background and text colors consistent.
4. Use teal as an accent rather than covering the page in bright colors.
5. Use the VM monogram consistently for portfolio branding.
6. Prefer real project screenshots over generated substitutes.
7. Keep decorative AI visuals subtle.
8. Let the projects remain the main visual focus.

## Judgment

The main design principle is:

**Frame the work, don't upstage it.**

The visual system exists to make the portfolio feel coherent and make the actual projects easier to understand. It should not become the main thing a visitor notices.
