# Portfolio Sitemap Pressure Test

## Prompt Used

Here is my portfolio proof statement:

“I can build practical machine-learning solutions from real-world data, and I want to prove that to a hiring manager looking for an entry-level machine-learning or data candidate. My portfolio will show how I take a real problem, work with data, build and validate a model, and turn the results into something useful rather than stopping at a model score. The main action I want that person to take is to contact me about an internship or entry-level opportunity.”

My sitemap is:

Home/Hero → Work/Case Studies → About → Contact.

Pressure-test this sitemap against my claim and my single desired action. Tell me whether every page earns its place, whether anything important is missing, and whether you would change anything. Be critical rather than simply agreeing.

## Pressure-Test Output

Claude concluded that four pages are appropriate and that no additional pages are needed.

### Key findings

- Home/Hero should clearly state the claim, feature 2–3 projects, and include a Contact CTA.
- Work/Case Studies is the core of the portfolio and should demonstrate the complete workflow: problem → data → cleaning → model → validation → useful output.
- About should remain short and truthful.
- Contact should focus on the main action and include email, LinkedIn, and resume.

### Elements to add

- Resume download link
- GitHub link for each case study
- Contact link in the navigation

### Changes to make

1. Feature case studies on the Home page.
2. End each case study with a Contact CTA.
3. Do not create separate Skills or Blog pages.

### Main risk identified

The portfolio needs projects with a usable output that demonstrate the claim, rather than only showing model scores.
